AI ROUTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
POST /api/analyze-github
→ Fetch repos via GitHub API → Claude analyzes
→ Returns skills JSONB with scores

POST /api/generate-roadmap
→ Input: year, field → Claude returns milestone list

POST /api/generate-interview-question
→ Input: company, round, question_number, previous_answers
→ Claude returns next interview question

POST /api/evaluate-interview
→ Input: all questions + answers → Claude evaluates
→ Returns scores + feedback + better answers

POST /api/generate-test
→ Input: type, difficulty → Claude returns 20 MCQs

POST /api/match-jobs
→ Input: student skills → Claude matches against jobs table
